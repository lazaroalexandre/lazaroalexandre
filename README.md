## Lázaro Alexandre

#### Engenheiro de Software | Analista de Sistemas | Desenvolvedor Mobile | Flutter | Dart | Android & iOS

Há mais de 3 anos atuando como engenheiro de software mobile e formado como analista de sistemas, participo de todo o ciclo de
desenvolvimento, desde o levantamento de requisitos, modelagem de sistemas até a entrega em produção, manutenção e monitoramento de
sistemas, projetando e desenvolvendo soluções para startups, empresas privadas, freelancers e projetos sociais. Como diferencial, desenvolvo
e mantenho aplicativos para Android e iOS com Flutter e Dart, integrando sistemas via API Rest (Dio), aplicando arquiteturas limpas e
escaláveis (Clean Architecture e MVVM), design patterns, testes automatizados, CI/CD, noções nativas Android/iOS (Method Channel),
gerenciamento de estado (Mobx, Bloc e GetX) e injeção de dependência (GetIt, Provider e Modular), aliando boas práticas de engenharia ao
uso de IA, a fim de entregar aplicações estáveis, performáticas e preparadas para crescer.
